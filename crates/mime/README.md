# symfony-mime (subset)

Private workspace crate of symfony-rs: the part of
[symfony/mime](https://github.com/symfony/mime) (v8.1.10, the demo's
pinned version) that HttpFoundation's `File` and `UploadedFile` use. It
is not a port of the whole component; e-mail messages, headers, parts,
encoders and crypto are not here.

| Module/API | Source behavior | Evidence | Limits |
|---|---|---|---|
| `mime_types` | Symfony `MimeTypes`: `getExtensions()`, `getMimeTypes()` (a custom map first, then upstream's tables, as given then lowercased), `registerGuesser()`, `guessMimeType()` over the guessers, last registered first, `getDefault()` / `setDefault()`; `MimeTypeGuesserInterface` as the `MimeTypeGuesser` trait | MimeTypesTest 13 of 13; upstream's `MAP` and `REVERSE_MAP` generated by `scripts/gen-mime-types.py` (`--check` finds a stale table) | `new()` registers `FileBinaryMimeTypeGuesser`, then `FileinfoMimeTypeGuesser`, as upstream, so the finfo port is asked first |
| `file_binary_mime_type_guesser` | Symfony `FileBinaryMimeTypeGuesser`: `file -b --mime -- %s 2>/dev/null` through `/bin/sh`, the path quoted as `escapeshellarg()` does, `./` before a leading `-`, the type read with upstream's pattern; support asked once per process | FileBinaryMimeTypeGuesserTest 7 of 8 (1 `n/a`: upstream skips it, the answer varies by system) | Answers are the host's `file` and magic database; not supported on Windows (as upstream); a custom command with a `sprintf()` conversion other than one `%s` and `%%` is refused (`Class::NotPorted`) |
| `fileinfo_mime_type_guesser` | Symfony `FileinfoMimeTypeGuesser`: PHP's `finfo` (`FILEINFO_MIME_TYPE`) replaced by `pure-magic` 0.5.2, a libmagic in safe Rust, with the `magic-db` 0.7.2 rules (BSD-2-Clause option; PLAN.md decision 18); the file's bytes only (no extension), up to 7 MiB; an empty file is `application/x-empty` and a one-byte file `application/octet-stream`, as libmagic; a doubled type is written once; one rule database per process | FileinfoMimeTypeGuesserTest 8 of 8; PHP 8.4.27's answers on 124 sample files (107 match) and on the 12,843 files of `upstream/symfony` (12,525 match): `tests/data/fileinfo.json`, every difference listed in `tests/data/fileinfo_differences.tsv` | Not PHP's libmagic: about 2.5% of files get another type, mostly source text (C++, JavaScript, JSON read as `text/plain`, `application/javascript` given as `text/javascript`), PGP keys, and some UTF-16 and Latin-1 text read as binary; the `$magicFile` parameter (a compiled `.mgc` file) and stream wrapper paths are not ported (`Class::NotPorted`) |
| `exception` | `LogicException`, `InvalidArgumentException`, `RuntimeException`, `ExceptionInterface`, with `instanceof` (`Error::is_a`) | The tests' `expectException` checks | One error type; messages are upstream's |

The `FileBinaryMimeTypeGuesser` tests run where `file` is installed
(Linux and macOS); elsewhere they are skipped, as upstream skips them
without a supported guesser. The finfo port runs on every platform.
Fixtures in `tests/fixtures` are upstream's `Tests/Fixtures`, except
`tests/fixtures/fileinfo`: test files of the `file` project at FILE5_45
(BSD licence, `tests/fixtures/fileinfo-COPYING`) and small files of common types made for this crate.
Record PHP's finfo answers again with `scripts/record.sh mime-fileinfo`
(it needs `upstream/`), and write the list of differences again with
`SYMFONY_RS_WRITE_DIFFERENCES=1 cargo test -p symfony-mime --test
fileinfo_recorded`. Regenerate the tables after a version move with:

```sh
python scripts/gen-mime-types.py
```
