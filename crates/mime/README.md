# symfony-mime (subset)

Private workspace crate of symfony-rs: the part of
[symfony/mime](https://github.com/symfony/mime) (v8.1.10, the demo's
pinned version) that HttpFoundation's `File` and `UploadedFile` use. It
is not a port of the whole component; e-mail messages, headers, parts,
encoders and crypto are not here.

| Module/API | Source behavior | Evidence | Limits |
|---|---|---|---|
| `mime_types` | Symfony `MimeTypes`: `getExtensions()`, `getMimeTypes()` (a custom map first, then upstream's tables, as given then lowercased), `registerGuesser()`, `guessMimeType()` over the guessers, last registered first, `getDefault()` / `setDefault()`; `MimeTypeGuesserInterface` as the `MimeTypeGuesser` trait | MimeTypesTest 13 of 13; upstream's `MAP` and `REVERSE_MAP` generated by `scripts/gen-mime-types.py` (`--check` finds a stale table) | `new()` registers only `FileBinaryMimeTypeGuesser`: `FileinfoMimeTypeGuesser` (PHP's finfo) is not ported, PLAN.md decision 18 |
| `file_binary_mime_type_guesser` | Symfony `FileBinaryMimeTypeGuesser`: `file -b --mime -- %s 2>/dev/null` through `/bin/sh`, the path quoted as `escapeshellarg()` does, `./` before a leading `-`, the type read with upstream's pattern; support asked once per process | FileBinaryMimeTypeGuesserTest 7 of 8 (1 `n/a`: upstream skips it, the answer varies by system) | Answers are the host's `file` and magic database; not supported on Windows (as upstream); a custom command with a `sprintf()` conversion other than one `%s` and `%%` is refused (`Class::NotPorted`) |
| `exception` | `LogicException`, `InvalidArgumentException`, `RuntimeException`, `ExceptionInterface`, with `instanceof` (`Error::is_a`) | The tests' `expectException` checks | One error type; messages are upstream's |

The guessing tests run where a guesser is supported (Linux and macOS with
`file`); elsewhere they are skipped, as upstream skips them without a
supported guesser. Fixtures in `tests/fixtures` are upstream's
`Tests/Fixtures`. Regenerate the tables after a version move with:

```sh
python scripts/gen-mime-types.py
```
