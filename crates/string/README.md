# Symfony String (Console's subset)

Private workspace crate: the parts of `symfony/string` v8.1.10 (`6c611097`)
that symfony/console needs. MIT; Symfony source, tests and the wcswidth
tables copyright Fabien Potencier. Unofficial, not affiliated with or
endorsed by Symfony.

| Contract | Source | Evidence |
|---|---|---|
| `UnicodeString`: NFC on construction, invalid UTF-8 refused (`from_bytes`) | `UnicodeString.php` | NFC of all 13,233 decomposable code points equals the oracle's ICU 72.1 (`tests/unicode.rs`) |
| `length()`, `slice()` by ICU's grapheme rules (`grapheme_strlen`, `grapheme_substr`) | `UnicodeString.php` | UnicodeStringTest `testLength` (10 rows, one skipped by upstream's own ICU-21661 guard), `testSlice` (25); 4,105 recorded sequences split as ICU splits them |
| `chunk()` by PCRE2 10.44's `\X`, `split()` without flags | `UnicodeString.php` | `testChunk` (10); the same 4,105 sequences split as PCRE2 splits them |
| `wordwrap()`, with PHP's native `wordwrap()` (`php::wordwrap`) written from the manual | `AbstractString.php` | `testWordwrap` (9); 4,005 native calls recorded from PHP |
| `width()` and `wcswidth()`: ANSI sequences and controls, zero-width and wide tables, emoji joiners, VS16, skin tones | `AbstractUnicodeString.php`, `Resources/data/wcswidth_table_*.php` | `testWidth` (57) |

Vectors: `scripts/record.sh string` (`oracle/recorders/string_unicode.php`,
`string_wordwrap.php`, and UnicodeStringTest's providers).
`src/tables.rs` is generated by `scripts/gen-string-tables.py` from
upstream's wcswidth tables and the oracle's `\p{ExtPict}` ranges.

## Dependencies

`unicode-normalization` (NFC) and `unicode-segmentation` (graphemes), from
unicode-rs, without dependencies of their own (PLAN.md stack table). They
are checked against the oracle above, not trusted.

## Differences

- **Unicode version.** The oracle's ICU and PCRE2 implement Unicode 15.0;
  the crates implement a newer version. 93 code points that extend a
  grapheme and 2 that prepend one are assigned only after 15.0: PHP treats
  them as unassigned characters (each its own grapheme), this crate as
  marks (`per_code_point_classes_differ_only_after_unicode_15`).
- **Indic conjuncts in `length()` and `slice()`.** The crate applies the
  conjunct rule (GB9c, Unicode 15.1); ICU 72.1 has its own older handling
  (ICU-21661): `अनुच्छेद` is 4 graphemes here and 5 in the oracle. Upstream's
  test skips that row on such an implementation, and so does the port.
  `chunk()` and `wordwrap()` follow PCRE2, which has no conjunct rule, and
  match the oracle.
- Not ported: the rest of the API (`ByteString`, `CodePointString`, case
  mapping, slugger, inflectors, `LazyString`), and `split()`'s limit and
  regex flags. Their manifest rows stay `pending`.
